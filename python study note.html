  • Python由荷兰人Guido于1989年发明。

1.4 重要问题及错题整理

1.

Python语言正确的标识符是_______。 

A. 2you
B. my-name
C. _item
D. abc*234
答案 C. _item

解释：这里容易把 _item 看错，实际上标识符可以用下划线开头，但不能出现 - 或 * 这种特殊符号。

2.

下面程序的输出是什么？ 

a,b=5,9
print(a, b)
A. 59
B. 5,9
C. 5□9 （□表示空格）
D. 5□□9 （5和9之间二个空格）
答案 C. 5□9 （□表示空格）

解释：一开始容易以为 print(a,b) 会直接输出 59，其实 print 默认会自动加一个空格。

3.

十进制19.625的二进制是[ ]。（整数部分用八位二进制表示） 

答案 00010011.101

解释：这种题容易漏掉小数部分，0.625 转换成二进制后是 .101。

4.

-78的原码是[ ] ，反码是[ ] ，补码是[ ]。 （用八位表示） 

答案 11001110, 10110001, 10110010

解释：这里最容易混淆的是反码和补码，补码是在反码基础上再加 1。

5.

从键盘输入三个数到a,b,c中，按公式值输出。

在同一行依次输入三个值a,b,c，用空格分开，输出 b*b-4*a*c的值。

输入格式:

在一行中输入三个数。

输出格式:

在一行中输出公式值。

输入样例:

3 4 5

输出样例:

-44

答案

a,b,c=map(int, input().split())
print(b*b-4*a*c)

解释：如果不加 map(int)，input() 读进来的数据默认还是字符串。

1.5 总结

  • Python是面向对象、解释型、跨平台语言。
  • 标识符不能数字开头，关键字不能作变量名。
  • Python区分大小写。
  • input()输入，print()输出。
  • input()默认输入字符串。
  • 重点：标识符 , input()/print() , 二进制 ,原码、反码、补码。

03 控制语句

3.1 if语句

1. 基本结构

if condition:
    statement1
    statement2
else:
    statement3

条件为 True 时执行 if 下面的语句；条件为 False 时执行 else 下面的语句。

else 不能单独使用。

2. 缩进和冒号

if money:
    print("Take a taxi")
    print("Go home")
  • if 条件: 后面必须有冒号 :
  • 属于 if 的语句必须缩进
  • 同一代码块缩进必须一致

3. 比较运算符

x > y
x < y
x == y
x != y
x >= y
x <= y

== 表示是否相等，!= 表示不等于。

4. 逻辑运算符

x and y
x or y
not x

and 表示并且，or 表示或者。

5. in / not in

pocket = ["paper", "money", "phone"]

if "money" in pocket:
    print("Take a taxi")
else:
    print("Walk")

in 可以判断元素是否在列表、元组、字符串中。

6. pass

if "money" in pocket:
    pass
else:
    print("Use card")

pass 表示什么也不做。

7. if-elif-else

score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")

elif 用于多条件判断。

8. 嵌套if

code = "R"
count = 15

if code == "R":
    if count < 20:
        print("OK")
    else:
        print("Wait")

重点：else 总是和同一缩进层级中最近的 if 匹配。

1. 基本结构

while condition:

while 循环在条件成立时反复执行循环体，条件不成立时结束。

    print(i)

重点：循环体内部通常要有改变条件的语句，否则容易产生死循环。

    print(count)
    count += 1

如果 while 正常结束，会执行 else。

    if number == 0:
        break

break 用于直接跳出当前循环。

    a += 1
    if a % 2 == 0:

    print(a)

continue 用于跳过本次循环。

核心：不断除以2，余数从前面插入列表。

m, n = map(int, input().split())
found = False

for x in range(m, n + 1):
    factors = []

    for i in range(1, int(x ** 0.5) + 1):
        if x % i == 0:
            if i != x:
                factors.append(i)

            other = x // i
            if other != i and other != x:
                factors.append(other)

    factors.sort()

    if sum(factors) == x:
        found = True
        print(f"{x} = {' + '.join(map(str, factors))}")

if not found:
    print("None")

解释：这题核心是找因子，容易漏掉另一半因子，所以代码里用了 other = x // i。

            print(matrix[i][j], i+1, j+1)

04 函数与文件

4.1 函数定义

1. 函数是什么

函数可以理解为：

输入数据 → 函数处理 → 输出结果

函数是可以重复使用的程序段。把一段语句命名，就是函数定义；使用这个名字运行语句块，就是函数调用。

def add(a, b):
    return a + b

result = add(3, 4)
print(result)
输出：
7

2. 为什么使用函数

函数的作用：

  • 避免重复代码
  • 提高程序结构清晰度
  • 方便查找错误
  • 把复杂程序分成多个功能模块

3. 函数基本格式

def function_name(parameters):
    statement1
    statement2
    return value

重点：

  • def 是定义函数的关键字
  • 函数名后面必须有 ()
  • 函数体必须缩进
  • 函数要先定义，再调用

4. lambda匿名函数

add = lambda a, b: a + b

print(add(3, 4))
输出：
7

重点：

  • lambda 可以创建简单函数
  • 不需要写 return
  • 表达式的结果就是返回值

4.2 参数与返回值

4.2.1 参数

1. 形参和实参

函数定义时的参数叫形参，函数调用时传入的值叫实参。

def add(a, b):
    return a + b

print(add(3, 4))

解释：

  • a, b 是形参
  • 3, 4 是实参

2. 位置参数

位置参数按顺序传递。

def sub(a, b):
    return a - b

print(sub(7, 3))
输出：
4

3. 关键字参数

关键字参数可以指定参数名，顺序可以改变。

def sub(a, b):
    return a - b

print(sub(b=5, a=3))
输出：
-2

4. 位置参数和关键字参数混合

如果同时使用，必须先写位置参数，再写关键字参数。

正确：

print(sub(7, b=3))

错误：

print(sub(a=7, 3))

5. 默认值参数

默认值参数是在函数定义时给参数设置默认值。

def say_myself(name, age, man=True):
    print(f"My name is {name}.")
    print(f"I am {age} years old.")
    if man:
        print("I am male.")
    else:
        print("I am female.")

调用：

say_myself("Tom", 27)
say_myself("Jane", 27, False)

重点：默认值参数必须放在没有默认值的参数后面。

正确：

def f(name, age, gender=True):
    pass

错误：

def f(name, gender=True, age):
    pass

6. 可变参数 *args

当输入值个数不确定时，可以使用 *args。

def add_many(*args):
    result = 0
    for i in args:
        result += i
    return result

print(add_many(1, 2, 3))
print(add_many(1, 2, 3, 4, 5))
输出：
6
15

重点：

  • *args 会把多个位置参数收集成一个元组

7. 关键字可变参数 **kwargs

**kwargs 用来接收多个 key=value 形式的参数。

def print_kwargs(**kwargs):
    print(kwargs)

print_kwargs(name="Tom", age=20)
输出：
{'name': 'Tom', 'age': 20}

重点：

  • **kwargs 会把关键字参数收集成字典

8. 参数顺序

如果普通参数、*args、**kwargs 一起使用，顺序一般是：

def func(name, *args, **kwargs):
    pass

例：

def mixed_function(name, *args, **kwargs):
    print(name)
    print(args)
    print(kwargs)

mixed_function("Tom", 1, 2, 3, age=20, city="Seoul")
输出：
Tom
(1, 2, 3)
{'age': 20, 'city': 'Seoul'}

4.2.2 返回值

1. return返回值

函数用 return 返回值。return 后面的表达式就是函数调用的返回值。

def add(a, b):
    return a + b

result = add(3, 4)
print(result)

2. 没有return返回None

如果函数没有 return，返回值是 None。如果 return 后面没有表达式，返回值也是 None。

def say():
    print("Hi")

result = say()
print(result)
输出：
Hi
None

重点：print() 只是输出，不等于函数有返回值。

3. 函数返回值永远只有一个

如果 return 后面有多个值，Python 会把它们作为一个元组返回。

def add_and_mul(a, b):
    return a + b, a * b

result = add_and_mul(3, 4)
print(result)
输出：
(7, 12)

也可以拆包接收：

result1, result2 = add_and_mul(3, 4)
print(result1)
print(result2)
输出：
7
12

4. return会结束函数

函数执行到 return 时，会立即结束。

def add_and_mul(a, b):
    return a + b
    return a * b

print(add_and_mul(2, 3))
输出：
5

第二个 return 不会执行。

5. return单独使用

return 可以不返回值，只用来提前结束函数。

def say_nick(nick):
    if nick == "bad":
        return
    print(f"My nickname is {nick}.")

say_nick("good")
say_nick("bad")

6. 变量作用域

函数内部定义的变量是局部变量，函数外部定义的变量是全局变量。形参也是局部变量。

a = 1

def vartest(a):
    a = a + 1

vartest(a)
print(a)
输出：
1

解释：函数内部的 a 和函数外部的 a 不是同一个变量。

7. global关键字

如果要在函数内部修改全局变量，可以使用 global。

a = 1

def vartest():
    global a
    a = a + 1

vartest()
print(a)
输出：
2

重点：考试知道用法即可，实际编程中尽量少用 global。

8. 列表、字典作为参数时可能被修改

列表和字典是可变对象，传入函数后，在函数内部修改会影响原对象。

def change_list(my_list):
    my_list.append(4)

a = [1, 2, 3]
change_list(a)
print(a)
输出：
[1, 2, 3, 4]

4.3 文件读写

1. open函数

文件操作使用 open()。

file_object = open(file_name, mode)

常见模式：

模式    含义
r       读取模式
w       写入模式
a       追加模式

2. 创建文件 / 写文件

f = open("newfile.txt", "w")
f.write("Hello, Python!\n")
f.close()

重点：

  • w 模式会创建新文件
  • 如果文件已存在，会清空原内容
  • 文件使用完最好 close()

3. 写入多行

f = open("newfile.txt", "w")

for i in range(1, 11):
    data = f"Line {i}\n"
    f.write(data)

f.close()

4. readline读取一行

f = open("newfile.txt", "r")

line = f.readline()
print(line)

f.close()

readline() 每次读取一行。

5. readlines读取全部行

f = open("newfile.txt", "r")

lines = f.readlines()
for line in lines:
    print(line.strip())

f.close()

重点：

  • readlines() 返回列表
  • strip() 可以去掉行尾换行符

6. read读取全部内容

f = open("newfile.txt", "r")

data = f.read()
print(data)

f.close()

read() 返回整个文件内容的字符串。

7. for循环读取文件

f = open("newfile.txt", "r")

for line in f:
    print(line.strip())

f.close()

文件对象可以直接用 for 循环逐行读取。

8. 追加模式

f = open("newfile.txt", "a")
f.write("New line\n")
f.close()

重点：

  • a 模式不会清空原文件
  • 新内容会添加到文件末尾

9. with语句

推荐使用 with，可以自动关闭文件。

with open("foo.txt", "w") as f:
    f.write("Life is too short, you need Python")

重点：

  • 不需要手动写 close()
  • 离开 with 块后文件自动关闭

10. 处理中文文件时指定编码

如果文件中有中文，建议写 encoding="utf-8"。

with open("chinese.txt", "w", encoding="utf-8") as f:
    f.write("你好，Python！")

with open("chinese.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

4.4 程序结构与模块

1. 模块

一个 Python 程序可以分布在不同文件中，每个文件可以看作一个模块。模块用 import 引入。

import module_name

模块名是 Python 文件名，不包含 .py。

2. from import

引入模块中的所有函数：

from module_name import *

引入模块中的单个函数：

from module_name import function_name

这样调用时不需要再写模块名。

3. 创建模块

triangle.py

import math

def area(a, b, c):
    s = (a + b + c) / 2
    return math.sqrt(s * (s - a) * (s - b) * (s - c))

main.py

import triangle

a = 12
b = 34
c = 26

print(triangle.area(a, b, c))

PPT中说明：模块是另一个 Python 文件，使用 import 模块名 就可以执行并调用其中内容。

4. sys模块和命令行参数

sys.argv 可以接收命令行参数。PPT也列出 sys.argv 是从程序外部向程序传递参数。

import sys

args = sys.argv[1:]

for i in args:
    print(i)

命令行运行：

python sys1.py aaa bbb ccc
输出：
aaa
bbb

    可能出错的代码

    出错后的处理代码

3. 指定异常类型

    result = 4 / 0
except ZeroDivisionError:
    print("division by zero")

  • try 不出错时不执行 except
  • 可以指定具体异常类型

5.8 总结

  • Python 是面向对象语言，一切皆对象。
  • 类用 class 定义，对象由类创建。
  • __init__ 是初始化方法，self 表示当前对象。
  • 模块就是 .py 文件，用 import 导入。
  • 包通常包含 __init__.py。
  • 异常处理使用 try-except。
  • 内置函数不用导入，例如 abs()、all()、any()。
  • 标准库需要 import，例如 sys、datetime、time。
  • 第三方库需要先安装，再导入，例如 pandas、flask。
  • pip install 包名 用于安装第三方库。
